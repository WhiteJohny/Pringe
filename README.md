# 🎵 Классификация музыкального настроения по аудио

Приложение для автоматического определения эмоциональной окраски музыкальных композиций с использованием машинного обучения и ClearML.

## 🌟 Возможности

- Автоматическая конвертация аудио в формат WAV
- Извлечение 70+ аудио-признаков различных категорий
- Классификация на 6 эмоциональных категорий
- Интеграция с ClearML для работы с моделями
- Высокая точность классификации

## 📋 Предварительные требования

### Установка FFmpeg
**Windows:**
```bash
# С помощью chocolatey
choco install ffmpeg
```

**Linux:**
```bash
sudo apt update
sudo apt install ffmpeg
```

**macOS:**

```bash
# С помощью Homebrew
brew install ffmpeg
```
## Настройка окружения
### Создайте файл .env в корневой директории проекта со следующим содержимым:

env
- MODEL_NAME=your_model_name_here
- CLEARML_WEB_HOST=https://app.clear.ml
- CLEARML_API_HOST=https://api.clear.ml
- CLEARML_FILES_HOST=https://files.clear.ml
- CLEARML_API_ACCESS_KEY=your_access_key_here
- CLEARML_API_SECRET_KEY=your_secret_key_here

### Где взять ключи:
- Зарегистрируйтесь на ClearML
- Перейдите в Settings → Workspace → API Access
- Скопируйте ваши ключи доступа

## 💡 Как это работает
### Процесс обработки:
- Конвертация аудио - автоматическое преобразование в WAV формат
- Извлечение признаков - анализ 70+ параметров звука
- Классификация - определение эмоциональной окраски через ClearML
- Вывод результата - отображение обнаруженных настроений

### Извлекаемые признаки:
- Темп (BPM) и ритмические паттерны
- Гармонические и ударные компоненты
- MFCC коэффициенты (40 признаков)
- Хроматические характеристики (12 тональностей)
- Спектральные свойства (яркость, ширина, контраст)
- Динамические параметры громкости

## 🐛 Решение проблем
Проблема: Ошибка конвертации аудио
Решение: Убедитесь, что FFmpeg установлен и доступен в PATH

Проблема: "Не удалось извлечь признаки"
Решение: Проверьте целостность аудиофайла и поддержку формата

Проблема: Ошибки ClearML соединения
Решение: Проверьте корректность .env файла и сетевые подключения

Проблема: Модель не загружается
Решение: Убедитесь, что MODEL_NAME соответствует существующей модели в ClearML
