# 🎯 YOLOv11 Детекция и Сегментация объектов

Приложение для обнаружения и сегментации объектов на изображениях, видео и в реальном времени с веб-камеры с использованием YOLOv11.

## 🌟 Возможности

- Обнаружение объектов в реальном времени
- **Новое**: Сегментация объектов (построение масок)
- Поддержка всех размеров моделей YOLOv11
- Работа с изображениями, видео и веб-камерой
- Простой и интуитивно понятный интерфейс
- Оптимизация производительности

## 🚀 Быстрый старт

### Установка
```bash
pip install ultralytics opencv-python
```

### Запуск
```bash
python main.py
```

## 💡 Пример работы
### После запуска выберите размер модели и режим работы:
```bash
Загрузка модели...
Выберите размер модели: nano/small/medium/large/xlarge
> nano
Модель загружена
Модель распознает следующие образы:

...
Выберите режим:
1 - Image, 2 - Video, 3 - webcamera

Введите путь до изображения: image.jpg
```

## 🖥️ Режимы работы

### 1. 📷 Обработка изображений
- Загрузите любое изображение
- Автоматическое обнаружение объектов
- Визуализация результатов с bounding boxes
- Возможность просмотра и закрытия по нажатию клавиши

### 2. 🎥 Обработка видео
- Загрузка видеофайлов
- Построчная обработка кадров
- Реальное время отображения результатов
- Выход по нажатию 'q'

### 3. 📹 Веб-камера
- Работа в реальном времени
- Непрерывная обработка видеопотока
- Минимальная задержка
- Выход по нажатию 'q'

## 🎯 Выбор задачи

### Детекция (Detection)
- Обнаружение объектов с bounding boxes
- Быстрая обработка
- Идеально для большинства задач

### Сегментация (Segmentation)
- Построение точных масок объектов
- Более детальная информация о форме
- Требует больше ресурсов

## 🏗️ Технологии

- **YOLOv11** - современная модель компьютерного зрения
- **OpenCV** - компьютерное зрение и обработка изображений
- **Ultralytics** - фреймворк для работы с YOLO
- **PyTorch** - глубокое обучение

## 🎮 Управление

- **q** - выход из режима просмотра
- **Любая клавиша** - закрыть изображение
- **q в главном меню** - выход из приложения

## 🐛 Решение проблем

**Проблема**: Модель не загружается
**Решение**: Проверьте подключение к интернету для загрузки весов

**Проблема**: Веб-камера не работает
**Решение**: Убедитесь, что камера не занята другим приложением

**Проблема**: Низкая производительность
**Решение**: Используйте модель nano или small

**Проблема**: Ошибка при выборе сегментации
**Решение**: Убедитесь, что выбранная модель поддерживает сегментацию
